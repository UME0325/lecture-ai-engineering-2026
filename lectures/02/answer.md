- ファインチューニングが向く場面・向かない場面についての考察：
  - 今回の結果で一番はっきりしたのは、LoRA で入るのは「振る舞い」で、「知識」は入りにくいことだった。形式は lora で 0.00 → 1.00 になり、用語集に無い語に確認を求める振る舞いも unknown_far で 0.75 まで入った（search は 0.00）。一方、定義の再現は、学習で見た言い回しそのまま（seen）でも 0.60 で、検索結果を渡すだけの search（1.00）に届かなかった。loss は 0.107 まで下がっていて、学習データの文はかなり覚えているはずなのに、評価では 4 割が別の語の定義や作り話になった
  - 覚えた知識は、学習で使った入口からしか取り出せなかった。lora の内容正解率は seen 0.60 → paraphrase 0.50 → alias 0.10 と、学習時の聞き方から離れるほど下がった。特に alias は、同じ定義を学習しているのに別名からはたどれず、HF Hub を「GitHub の…」と答えるように、名前の字面から連想して作った。検索は別名を辞書（`aliases`）で正式名に結び付けるので 0.90 を保った。知識を「名前 → 定義」の対応で持つなら、その対応を明示的に持てる検索のほうが、言い回しや別名に強い
  - LoRA で講座の文体を学んだことで、作り話がもっともらしくなった。lora の誤答には「本講座では第2回の演習で…」「2026年10月に正式にオープン」のように、用語集の定義の書き方（末尾に講座での扱いを添える）をまねた、存在しない講座の事実が多く混ざった。学習前の base の誤答は一般的な説明で、講座の資料と見比べれば外れていると分かるが、lora の誤答は講座の用語集の文体で書かれているので、受講生が信じやすい。学習支援エージェントの用途では、この「それらしい誤り」がいちばん害が大きいと考える
  - 検索だけでも足りなかった。search は 0.8B のモデルに検索結果を渡すだけで、形式を守れず（needs_review を書かない）、「見つかりませんでした」という結果を受け取っても 16 問すべてで断定した。つまり「根拠が無いときに止まる」という振る舞いは、プロンプトの指示と検索結果だけでは小さなモデルに入らず、ここは学習が効いた
  - そのため、今回のデータで最も良かったのは、知識は検索で渡し、形式と「知らないと言う」振る舞いは学習で付ける組み合わせ（lora_search、0.88）だった。ただし、名前や分野が学習データに近い語（unknown_near）は lora_search でも 0.38 のままで、検索が「見つかりませんでした」と返しても、学習で付いた「この分野なら答えられる」という傾向が勝って断定した。根拠なしの学習例を、学習データの分野に近い語（重み減衰・早期終了のような学習の用語）でも用意する必要があると考える。また、検索の部分一致で「継続事前学習」に「事前学習」、「MCPインスペクター」に「MCP」が返ったように、検索の誤ヒットはモデルの側では防げないので、検索結果に一致の種類（完全一致・部分一致）を付けて渡す、部分一致のときは確認を求める、といった検索側の工夫も要る
  - まとめると、ファインチューニングが向くのは、出力の形式、口調・文体、「根拠が無ければ確認を求める」のような振る舞いを、プロンプトでは守れない小さなモデルに安定して守らせたい場面。今回のように 201 件・数分の学習で形式は 100% になり、推論時のプロンプトも短くできる。向かないのは、事実（用語の定義、締切、手順）を覚えさせて答えさせたい場面。言い換えや別名に弱く、間違いがもっともらしくなり、内容を変えるたびに学習し直す必要がある（用語集は講座中に更新され、実際に本家の更新で ADK の定義が変わったため、学習データを作り直した）。検索なら、用語集の JSON を書き換えるだけで済み、答えの根拠（どの項目を見たか）も示せる。学習支援エージェントには、第3回のツールによる用語集検索を知識の入口にし、ファインチューニングは形式と振る舞いを整えるために使うのがよいと考える
  - 今回の限界：test は 60 問で、区分ごとでは 8〜24 問しかないので、1 問の差が 4〜12 ポイントになる。また seed を固定しても GPU 上の学習は完全には再現しないので、数値は 1 回の実行の結果である。内容の採点は文字 2-gram の類似度で、定義の 1 文目だけを正しく答えても類似度は 0.3〜0.7 になるため、厳しめの基準（content_rate）と、正しい語に一番近いかだけを見る緩い基準（identified_rate）を並べた。どちらで見ても、条件の順位は変わらなかった
