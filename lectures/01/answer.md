## 宿題

- 取り組んだレベル：実装
- やったこと：
  - `app/ask.py` に `--chat` オプションを追加し、会話履歴を保ったまま続けて質問できるようにした。
    - `Conversation` クラスがこれまでの質問（role=`user`）と回答（role=`model`）を `history` に積み、毎回その全部を `generate_content` の `contents` として送る。API 自体は前の会話を覚えていないため、履歴を送るのはクライアント側の役割になる。
    - API エラーで失敗したターンは履歴に積まない。エラーが出ても会話は終了せず、続けて質問できる。
    - `exit` / `quit` / `終了` / 空行 / Ctrl-D で終了する。
  - あわせて `--temperature` オプションを追加した（`types.GenerateContentConfig(temperature=...)` を渡す）。
  - `tests/test_ask.py` を追加した。偽クライアントで、2ターン目の `contents` に1ターン目の質問と回答が含まれること、失敗ターンが履歴に残らないこと、トークン数の表示などを確かめる（APIキー不要）。
- 結果：
  - `uv run pytest -q`：17 passed。最初はトークン数が `None` のケースのテストデータが誤っていて1件失敗したので、テストを直した。
  - 動作確認（`uv run python -m app.ask --chat`）：

    | ターン | 質問 | 回答 | 入力 / 出力トークン |
    |---|---|---|---|
    | 1 | 私の名前はタロウです。覚えてください。一言で返事して | 了解です、タロウさん。 | 17 / 7 |
    | 2 | 私の名前は何ですか？一言で | タロウさんです。 | 34 / 5 |
    | 3 | 最初に私が何と言ったか一文で教えて | 「私の名前はタロウです。覚えてください。」と言いました。 | 51 / 14 |

  - 比較：履歴なしの `app.ask` で「私の名前は何ですか？一言で」と聞くと「わかりません。」（入力 9 / 出力 3）。
  - `--temperature 1.5` を指定して「LoRAとは何ですか？一文で」と聞くと、エラーにはならず普通に回答した（入力 10 / 出力 47）。値が実際に効いたのか無視されたのかは、この1回では判断できない。
- 工夫した点：
  - API は状態を持たない（前の会話を覚えていない）。そこで SDK の `client.chats.create()` に任せず、履歴を自前のリストで管理して毎回全履歴を送る実装にした。「記憶」がモデルではなくクライアント側の設計であることを、コードの上で確かめるため。
  - API エラーのターンは履歴に積まないようにした。積んでしまうと回答のない user ターンが残り、次の送信で user が2回続いて、user / model の交互の並びが崩れるため。
  - 偽クライアントのテストで、画面の出力ではなく「API に何が送られたか（`contents`）」そのものを検証した。
- 考察（評価してほしい点）：
  - **コストはターン数の2乗で増える**：入力トークンは 17 → 34 → 51 と、毎ターン約 17（1ターン分の質問と回答）ずつ増えた。1ターンの大きさが一定なら、k ターン目の入力は約 17k、N ターンの累積入力は 17 × N(N+1)/2 で、N² に比例する。長い会話ほど料金・トークン単位の上限・コンテキストウィンドウに早く達するので、古い履歴の要約や、直近 N ターンへの絞り込みが必要になる。
  - **記憶の正体は文脈**：同じ「私の名前は何ですか？」を、履歴ありでは「タロウさんです。」、履歴なしでは「わかりません。」と答えた。この対照実験で、モデルが覚えているのではなく、送った文脈に情報があるかどうかだけで答えが決まることを示した。
  - **演習の現象も同じ原因**：演習で講座固有の「3レベル」を聞くと、2回とも「分からない」とは言わず一般論でもっともらしく答えた。これも、講座の知識が文脈にないためである。会話の記憶も講座の知識も「必要な情報を文脈に入れる」設計で解決でき、第3回の用語集検索エージェントはその後者にあたると考える。
- 難しかった点・疑問：
  - temperature は非推奨になったと資料にあるが、`--temperature 1.5` を指定してもエラーにはならず、効いたかどうかを1回の実行では判別できなかった。確かめるには、同じ質問を temperature 0 と高い値で複数回ずつ実行し、回答のばらつきを比べる必要がある（基礎レベルの課題）。
  - トークン数が `None` のケースのテストデータに誤りがあり、最初は1件失敗したため修正した。
